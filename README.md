# Page-Replacement-Simulator

A Python-based graphical application that simulates three Page Replacement Algorithms: FIFO, LRU, and Optimal.

# Project Overview

Page Replacement Algorithms are memory management techniques used by operating systems to replace pages when the available memory frames are full.

This simulator allows users to input a page reference string and the number of available frames. It then performs the FIFO, LRU, and Optimal algorithms to determine page hits and page faults.

The application provides a step-by-step simulation, displaying frame contents, HIT and FAULT status, total hits, total faults, and the performance results of each algorithm.
